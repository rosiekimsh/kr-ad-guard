# 도박배너 차단기 (KR Ad Guard)

**한국어** · [English](README.en.md)

한국 사이트에 넘쳐나는 **불법 도박·성인·불법 의약품 배너**를 자동으로 찾아 숨기는 크롬 확장 프로그램입니다.
이미지 속 글자를 **내 컴퓨터 안에서** 읽어(OCR) 판별하기 때문에, 주소가 계속 바뀌어 일반 광고 차단 목록으로는 잘 안 잡히는 배너도 대응합니다.

🔒 **서버 없음 · 계정 없음 · 추적 없음** — 이미지와 방문기록은 밖으로 나가지 않습니다.
🧠 **쓸수록 똑똑해집니다** — 놓친 배너를 한 번 지우면 기억해서 다시 안 보여줍니다.

> 💡 놓치는 배너가 있거나 정상 이미지가 숨겨졌다면 팝업의 **이 페이지 복구**를 누르거나 **배너 직접 지우기**를 쓰세요.

## 설치 (1분, 크롬)
1. [**Releases**](../../releases/latest)에서 `kr-ad-guard-v0.6.0.zip`을 받아 **압축 풀기**
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 선택. 끝!

> 압축 푼 폴더는 **지우지 마세요**(지우면 확장이 사라집니다). 업데이트할 땐 새 zip을 **같은 폴더에 덮어쓰고** `chrome://extensions`에서 새로고침(↻)을 누르면 학습한 내용이 유지됩니다.
> Chrome 109 이상에서 테스트했습니다. 다른 크로미움 계열 브라우저는 확인하지 않았습니다.

## 사용법
| 하고 싶은 것 | 방법 |
|---|---|
| 얼마나 숨겼는지 보기 | 툴바 아이콘의 숫자 뱃지 |
| **기본 내장 목록** | 확인된 불법 배너의 지각 해시(이미지 아님)가 확장에 함께 들어 있어, 설치 직후부터 글자 없는 배너도 막습니다. 내가 '복구'한 이미지는 내장 목록보다 우선합니다 |
| **광고 팝업 자동 닫기** | 광고 배너가 든 팝업창이 뜨면 **'오늘 그만보기'를 자동으로 눌러** 줍니다. 광고가 아닌 팝업은 그대로 둡니다 |
| **안 막힌 배너 지우기** | 팝업 → **🖱 배너 직접 지우기** → 배너 클릭 (Esc 취소). 이미지·배경이미지·박스형·iframe 광고 모두 가능. 지운 건 **다음 방문부터 자동으로 숨김** |
| 이미지에서 바로 신고 | 이미지 우클릭 → **도박 배너로 신고** |
| 잘못 숨겨졌을 때 | 팝업 → **이 페이지 복구** (그 배너는 다시 안 막힙니다) |
| 더 많이/적게 막기 | 팝업 → 민감도: 보수적 / 균형 / 공격적 |
| 특정 사이트에서 끄기 | 팝업 → 이 사이트에서 사용 해제 |
| 뭐가 걸리는지 눈으로 보기 | 팝업 → 테스트 모드 (숨기지 않고 빨간 테두리) |
| 학습 내용 옮기기·초기화 | 팝업 → 학습 목록 내보내기 / 가져오기 / 초기화 |

## 어떻게 동작하나요
1. 링크 안의 가로로 긴 배너 이미지(배경이미지·iframe 포함)를 후보로 수집
2. 링크·파일명 패턴, 같은 크기 배너 묶음, 도박 홍보 페이지 문맥으로 1차 점수
3. 후보 이미지를 **기기 안에서** 한국어 OCR(Tesseract)로 읽고, 첫충·페이백·콤프 같은 키워드를 **자모 단위 퍼지 매칭**(OCR 오인식 보정)으로 점수화
4. 점수가 기준 이상이면 숨김. 확실한 배너는 **지각 해시**로 기억해 다음엔 OCR 없이 즉시 차단

합법 사행성(체육진흥투표권·복권 등)과 암호화폐 정보 배너는 감점해 오탐을 줄였습니다.

## 개인정보
**운영자 서버가 없습니다.** 이미지·방문기록·학습 목록은 모두 내 기기 안에서만 처리·저장되고 외부로 전송되지 않습니다. 광고·분석·추적 도구도, 원격 코드 실행도 없습니다. 자세한 내용: [PRIVACY.md](PRIVACY.md)

## 정확도 (솔직하게)
개발자가 모은 **작은 표본(배너 27장 + 합성 페이지)** 으로 잰 값이라, 실제 사이트에서는 다를 수 있습니다.
- 일반 페이지 배너 20장 중 17장 차단, 정상 이미지 오탐 0
- iframe 광고 8/8, 정상 3장 오탐 0
- 글꼴이 매우 화려하거나 글자가 왜곡된 배너, 브랜드명만 있는 배너는 OCR이 못 읽어 놓칠 수 있음 → **직접 지우기**로 보완

## 알려진 한계
- 캔버스·비디오로 그린 광고, 극단적 비율의 이미지는 자동 탐지가 안 됩니다(직접 지우기는 이미지·배경·iframe 가능)
- 핫링크 방지로 이미지를 못 가져오면 판별할 수 없습니다
- 가장자리를 많이 자른 이미지는 해시가 달라져 학습으로 알아보지 못합니다
- Safari·모바일 버전은 아직 없습니다

## FAQ
**정상 이미지가 숨겨졌어요.** 팝업 → *이 페이지 복구*. 그 이미지는 정상 목록에 들어가 다시 안 막힙니다. 반복되면 [이슈](../../issues/new/choose)로 알려 주세요.
**왜 '모든 사이트 접근' 권한이 필요한가요?** 어떤 사이트에서든 배너를 찾고 이미지를 분석해야 하기 때문입니다. 데이터는 밖으로 나가지 않습니다([권한별 이유](PRIVACY.md)).
**"매니페스트 파일이 없거나 읽을 수 없습니다"라고 나와요.** 거의 항상 폴더를 잘못 고른 경우입니다. ① zip을 먼저 **압축 풀기**(zip을 더블클릭해 안을 보는 것만으로는 안 됩니다) ② 압축 푼 폴더를 열어 `manifest.json`이 **바로 보이는지** 확인 ③ 폴더 안에 폴더가 또 있으면(`이름/이름/…`) `manifest.json`이 있는 안쪽 폴더를 선택하세요. zip 파일 자체를 고르면 안 됩니다.

**폴더를 옮겼더니 학습 내용이 사라졌어요.** 개발자 모드로 로드한 확장은 폴더 경로가 바뀌면 다른 확장으로 취급됩니다. 옮기기 전에 *학습 목록 내보내기*를 해 두세요.

## 개발
```bash
npm test                 # 점수·해시 단위 테스트 (Node 18+, 의존성 없음)
./scripts/package.sh     # dist/ 에 배포용 zip 생성
```
`extension/scoring.js`(키워드·점수) · `content.js`(탐지·숨김·직접 지우기) · `offscreen.js`(OCR·해시) · `background.js`(중계·캐시·학습 목록) · `phash.js`(지각 해시) · `popup.*`(설정 UI) · `lib/`(Tesseract.js와 한국어 모델)

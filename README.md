# 도박배너 차단기 (KR Ad Guard)

한국 사이트에 많은 **불법 도박·성인·불법 의약품 배너**를, 구조 분석과 **기기 안 OCR**로 알아내 숨기는 크롬 확장 프로그램입니다.
일반 광고 차단 목록으로는 잘 안 잡히는 이미지 배너(직접 삽입, 주소가 계속 바뀜)를 대상으로 합니다.

> ⚠️ **베타입니다.** 놓치는 배너가 있을 수 있고, 드물게 정상 이미지를 숨길 수 있습니다. 그럴 땐 팝업의 **이 페이지 복구**를 누르세요.

## 설치 (3줄)
1. [Releases](../../releases)에서 zip을 받아 **압축 풀기** (또는 이 저장소를 clone 하고 `extension/` 폴더 사용)
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 선택

압축 푼 폴더는 지우지 마세요. (Chrome 109 이상에서 테스트했습니다. 다른 크로미움 계열 브라우저는 확인하지 않았습니다.)

## 특징
- **구조 + OCR**: 링크 안의 가로로 긴 배너 이미지를 찾고, 기기 안에서 한국어 OCR로 글자를 읽어 점수를 매김. OCR 오인식은 자모 단위 퍼지 매칭으로 보정
- **쓸수록 학습 (서버 없음)**: 확실히 차단한 배너는 스스로 기억하고, 놓친 배너는 **🖱 배너 직접 지우기**(클릭) 또는 이미지 **우클릭 → 도박 배너로 신고**. 지운 이미지는 해시·주소로 기억해 다음 방문부터 자동으로 숨김
- **오탐 교정**: 복구한 배너는 정상 목록에 들어가 같은 오탐이 반복되지 않음
- **iframe 광고, 배경이미지 배너, 페이지 문맥**(도박 홍보 페이지의 배너 격자) 대응
- **저사양 배려**: 기기 사양에 맞춰 OCR 워커 수 조절, 화면 가까운 배너부터 처리, 놀면 메모리 반환
- 민감도 3단계(보수/균형/공격), 사이트별 끄기, 테스트 모드(숨기지 않고 빨간 테두리)

## 개인정보
**운영자 서버가 없습니다.** 이미지·방문기록·학습 목록은 모두 내 기기 안에서만 처리·저장되고 외부로 전송되지 않습니다. 자세한 내용은 [PRIVACY.md](PRIVACY.md).

## 정확도 (솔직한 수치)
개발자가 모은 **작은 표본(배너 27장 + 합성 페이지)** 으로 잰 값입니다. 실제 사이트에서는 다를 수 있습니다.
- 일반 페이지 배너 20장 중 17장 차단, 정상 이미지 오탐 0
- iframe 광고 8/8, 정상 3장 오탐 0
- 글꼴이 매우 화려하거나 글자가 왜곡된 배너, 브랜드 이름만 있는 배너는 OCR이 못 읽어 놓칠 수 있음 → 직접 지우기로 보완

## 알려진 한계
- 캔버스/비디오로 그린 광고, 극단적인 비율의 이미지는 자동 탐지 안 됨(직접 지우기는 이미지·배경·iframe 가능)
- 핫링크 방지로 이미지를 못 가져오면 판별 불가
- 가장자리를 많이 자른 이미지는 해시가 달라져 학습으로 알아보지 못함
- 합법 사행성(체육진흥투표권 등)·암호화폐 정보 배너는 감점해 오탐을 줄이지만 완벽하지 않음
- Safari/모바일 버전 없음

## 개선에 참여하기
광고가 많은 페이지에서 팝업 → **테스트 리포트 복사** → [이슈](../../issues/new/choose)에 붙여 주세요. 도메인이 `ab***.com` 형태로 일부 가려져 있습니다. **실제 광고 이미지나 사이트 주소는 올리지 마세요.** 자세한 건 [CONTRIBUTING.md](CONTRIBUTING.md).

## 개발
```bash
npm test                 # 점수·해시 단위 테스트 (Node 18+, 의존성 없음)
./scripts/package.sh     # dist/ 에 배포용 zip 생성
```
파일 구성: `extension/scoring.js`(키워드·점수, 가장 먼저 튜닝) · `content.js`(탐지·숨김·직접 지우기) · `offscreen.js`(OCR·해시) · `background.js`(중계·캐시·학습 목록) · `phash.js`(지각 해시) · `popup.*`(설정 UI) · `lib/`(Tesseract.js와 한국어 모델)
